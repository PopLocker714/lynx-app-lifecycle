# App lifecycle

Перед правками читать CONTRIBUTING.ru.md и docs/compatibility.ru.md. Сохранять небольшую
TS/native структуру, wire names, public signatures и разделение app/page. Проверка: bun run check;
при native изменениях — check:android/check:ios и независимое review. Consumer/device evidence
проверяется отдельно. Публикация заблокирована; push/release без разрешения не выполнять.
